# Бот подписки на материалы МГУ — основа (без оплаты)

aiogram 3.29+ (нужен Bot API 10.1 с rich-сообщениями), SQLite, Python 3.11+.

## Запуск на сервере

Нужен VPS с Ubuntu 22.04/24.04 **за пределами России**: с российских серверов Telegram API
местами недоступен.

```bash
# со своего компьютера, из папки, где лежит subbot.zip
scp subbot.zip root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
apt-get update && apt-get install -y unzip && unzip subbot.zip && cd subbot && bash install.sh
```

Бот ставится в `/opt/subbot`, сам запускается после перезагрузки и падений,
раз в сутки копирует базу в `/opt/subbot/backups`.

- логи: `journalctl -u subbot -f`
- поменять настройки: `nano /opt/subbot/.env`, потом `systemctl restart subbot`
- обновить код: залить новую папку и снова `bash install.sh` (`.env` и база не тронутся)

Локально для теста: `pip install -r requirements.txt && python main.py`.

Канал необязателен. Если указан `CHANNEL_ID`, бот должен быть в нём админом с правом
приглашать и удалять участников: тогда он сам пускает подписчиков по заявке и удаляет тех,
у кого кончился срок.

## Материалы в закрытом канале

Материалы лежат в канале, бот пускает туда только подписчиков:

1. Сделай бота админом канала с правами «Добавлять участников» и «Блокировать пользователей».
2. Перешли боту любой пост из канала — он проверит права и подключит канал (`/channel` — проверить).
3. В настройках канала: тип «частный», удалить старые пригласительные ссылки, включить
   «Запретить копирование».

Как это работает: «📚 Материалы» даёт подписчику ссылку-заявку. Заявку бот одобряет только
при активной подписке, поэтому ссылку не страшно слить. Когда подписка кончается, бот убирает
человека из канала; после оплаты пускает снова.

Тех, кто уже сидел в канале до бота, бот не знает — выдай им доступ: `/grant @ник дни`.

Если канал не подключён, бот работает по-старому: каталог предметов и выдача файлов в боте
(`/addsubject`, `/upload`).

## Оплата переводом по СБП

Включается `MANUAL_PAY=1` и номером в `MANUAL_PAY_PHONE`. Банки — в `MANUAL_PAY_BANKS`
через запятую: бот закрепляет за каждым человеком один банк и раздаёт их по очереди,
так что переводы делятся поровну. В уведомлении владельцу и в `/stats` видно, на какой банк пришло.

1. Человек выбирает тариф → «🏦 Перевод по СБП». Бот показывает номер и сумму (ровно цена тарифа).
2. Он переводит и жмёт «Я перевёл» — бот сразу заносит оплату в базу и включает доступ.
3. Владельцу приходит уведомление «занесено в базу»: кто, тариф, до какого числа.
   Если перевода не было — «↩️ Отменить»: бот снимет оплаченные дни и отключит человека.
4. Перевёл, но не нажал кнопку — `/paid @ник m1`.
5. Дальше бот сам напоминает о продлении за 3 дня и за 1 день и отключает по окончании.

## Что проверить при тесте

- [ ] переслать пост из канала → бот пишет «Канал подключён»; `/channel` — права в порядке
- [ ] без подписки «📚 Материалы» показывает тарифы; заявка по ссылке отклоняется
- [ ] после оплаты приходит кнопка «Открыть канал», заявка принимается сама
- [ ] в канале нельзя переслать и сохранить посты («Запретить копирование»)
- [ ] `/revoke @ник` или конец срока → бот убирает человека из канала
- [ ] перевод по СБП: «Я перевёл» → доступ сразу, владельцу уведомление
- [ ] «↩️ Отменить» у владельца → дни сняты, человеку сообщение
- [ ] `/paid @ник m1` заносит оплату вручную
- [ ] промокод: `/addpromo TEST 20`, ссылка `?start=p_TEST`, цена со скидкой
- [ ] рефералка: второй аккаунт по ссылке друга, тестовая оплата → другу +7 дней
- [ ] подарок: «🎁 Подарить» → тестовая оплата → ссылка → активировать с другого аккаунта
- [ ] `/grant`, `/revoke`, `/info`, `/stats`, `/export`
- [ ] рассылка: `/broadcast former`
- [ ] вопрос админу и ответ реплаем
- [ ] конец подписки: `/grant id 1`, потом в базе поставить `expires_at` в прошлое —
      через пару минут придёт сообщение о конце и скидка «вернись» (один раз на человека)

## Что дальше

Оплата подключается в одну точку — `services.on_paid()`: ЮKassa или звёзды создают
платёж через `create_payment()` и по факту оплаты вызывают `on_paid()`. Промокоды,
рефералка, подарки и статистика уже на это завязаны. Перед запуском — `TEST_PAYMENTS=0`.
